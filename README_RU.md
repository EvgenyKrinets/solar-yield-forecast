# Solar Yield Forecast — руководство по установке

Интеграция Home Assistant для системы 48 × 670 Вт = 32,16 кВтp в пяти группах. Использует Open-Meteo, корректирует прогноз по реальной суточной энергии и ведёт независимую оценку ошибки прогнозов на будущие дни.

## HACS (настройка один раз)

1. Открой HACS → меню → Custom repositories.
2. Добавь `https://github.com/EvgenyKrinets/solar-yield-forecast` и выбери тип **Integration**.
3. Установи **Solar Yield Forecast** и перезапусти Home Assistant.
4. Settings → Devices & services → Add integration → **Solar Yield Forecast**.
5. Проверь широту, долготу и датчики:
   - `sensor.daily_pv_generation` — энергия за сутки в кВт·ч;
   - `sensor.total_dc_power` — текущая мощность PV (Вт).

После подключения интеграция загружает погоду по каждой из пяти ориентаций и показывает прогноз на сегодня, завтра, 7 дней, почасовой профиль и метрики калибровки.

**Начиная с версии 0.4.0 карточка включена в интеграцию и загружается автоматически.** Не нужно скачивать JavaScript в `/config/www/` или добавлять его в Dashboard Resources. После установки/обновления через HACS перезапусти Home Assistant и обнови браузер. Добавь карточку вручную из `dashboard.yaml` или выбери Solar Comparison Card в редакторе карточек.

## Конфигурация панелей

| Группа | Кол-во | Наклон | Азимут |
|---|---:|---:|---:|
| G1 | 21 | 10° | 290° |
| G2 | 10 | 30° | 290° |
| G3 | 10 | 15° | 30° |
| G4 | 5 | 30° | 30° |
| G5 | 2 | 30° | 130° |

Азимут задаётся от севера по часовой стрелке. В Open-Meteo выполняется автоматическое преобразование.

## Достоверность прогноза

- `Training Error` — ошибка подгонки на исторических днях, **не** точность будущего прогноза.
- `Forward Forecast Error` — ошибка сохранённых прогнозов, выпущенных минимум за день до даты. В начале она может быть недоступна до накопления наблюдений.
- В течение дня прогноз `Today` меняется: фактически произведённая энергия + погодная оценка оставшегося дня.
- Мощность `Power Now` — средняя за час, а не мгновенное измерение.
- Долговременные ограничения экспорта и заряда могут привести к недоучёту потенциальной генерации.

## Обновление

В HACS обнови интеграцию до последней доступной версии. Не удаляй интеграцию и её данные из HA: история сохранена в `.storage`.

## Приватность

Фактическая история пользовательской выработки и персональные координаты не публикуются в GitHub. При установке используй свои координаты.

## Условия

Открытый исходный код, лицензия MIT. Без AI, без API-ключей.

## Широкий график на 3 колонки

Используй **Sections** dashboard, а не Masonry. В редакторе Dashboard настрой максимальное число колонок минимум 3 и создай секцию с **Column span = 3** (если доступно в твоей версии интерфейса). Добавь Solar Comparison Card в эту секцию, в её настройках выбери **Full width card**. В YAML карточки предусмотрено `grid_options: {columns: full, rows: 8}`. При узком экране секция адаптивно занимает всю доступную ширину. В Masonry отдельная карточка не умеет занимать три стандартные колонки. Если ранее был добавлен ручной ресурс `/local/solar-comparison-card.js`, удали его в Dashboard Resources, чтобы не загружать старый вариант параллельно.

## Обновление с v0.3.0 на v0.4.0

Обнови интеграцию в HACS, перезапусти HA, очисти кэш страницы один раз (Ctrl+Shift+R). Сохрани существующую config entry: при удалении интеграции можно лишиться сохранённых параметров.

## Выбор большой или маленькой карточки (v0.4.1)

При добавлении карточки из интерфейса Dashboard выбери **Solar Comparison — широкий** (тип `custom:solar-comparison-card`) или **Solar Comparison — компактный** (тип `custom:solar-comparison-compact`). Обе загружаются автоматически вместе с интеграцией. Добавляй на нужный Dashboard и перетаскивай в выбранную секцию; Home Assistant определяет её расположение, интеграция не может произвольно переставлять карточки во всех Dashboard. В Sections широкая карточка занимает полную ширину секции; компактная — около шести ячеек сетки. Чтобы сделать широкой на три колонки, задай секции `Column span = 3`. После обновления перезапусти HA и обнови страницу.
