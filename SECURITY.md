# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please do not disclose a vulnerability in a public issue. Use GitHub's **Report a vulnerability** / private security advisory feature for this repository and include:

- affected version;
- impact;
- reproduction steps;
- suggested mitigation, if known.

Do not include real credentials, long-lived tokens, exact residential coordinates or private Home Assistant data. A maintainer will acknowledge a valid report and coordinate disclosure after a fix is available.
